# tw-scam-patterns

台灣官方公布的詐騙手法結構化資料集（繁體中文）。每一筆都附官方出處與查證日期。

> **這不是官方資料。** 本資料集由 AI 自動整理官方公開資訊，可能有錯漏。遇到可疑情況請直接撥打 **165** 反詐騙專線，或查詢 [165 打詐儀錶板](https://165dashboard.tw/)。

## 一般讀者請先看

👉 **[白話防詐指南（GUIDE.md）](GUIDE.md)**：8 種常見詐騙的白話說明、警訊、該怎麼做，以及跨類別的共通手法。

## 內容

`data/scam_patterns.csv`，目前 32 筆，涵蓋 8 類：假檢警、假冒 165、假冒親友、解除分期付款、假冒客服、假網拍、假投資、假交友。

| 欄位 | 說明 |
|---|---|
| `id` | 編號（類別代碼-流水號） |
| `category` | 詐騙類別 |
| `pattern_zh` | 常見話術或手法 |
| `how_to_spot_zh` | 辨識要點 |
| `what_to_do_zh` | 建議動作 |
| `source_agency` | 來源機關 |
| `source_url` | 官方原文連結 |
| `source_published` | 官方原文發布日 |
| `checked_at` | 本資料集查證日 |

## 收錄原則

- 只收官方機關（中央部會、警政署等）公開發布的內容；新聞媒體與社群貼文只當線索，不收錄。
- 只描述手法與辨識特徵。**不收錄任何個人、電話號碼、帳號、網址、LINE ID**，避免誤傷被冒用的無辜者。
- 每筆都有官方原文連結與查證日期。發現錯誤會在 24 小時內更正，並在 CHANGELOG 留下紀錄，不直接刪除。
- 不提供法律、投資或個人化建議。
